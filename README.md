# 🚀 JS Quiz

JS Quiz is a small interactive web app for testing core JavaScript knowledge. It presents a randomized set of multiple-choice questions, tracks your score, and shows a results summary at the end.

---

## 🌍 Live Demo

https://sevanton88.github.io/js-quiz/

---

## ✨ Features

- Randomly selects 10 questions for each round
- Shuffles answer options while preserving the correct answer
- Displays live progress and current score during the quiz
- Shows a final results screen with correct, wrong, and percentage stats

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

---

## ⚡ Getting Started

1. Clone the repository  
2. Open `index.html` in your browser  

---

## 🎯 Project Goal

The goal of this project was to practice DOM manipulation, event handling, array shuffling, and building a polished interactive UI using vanilla JavaScript.
